# Informe base de investigación de usuarios

## Contexto
La ficha del proyecto identifica que necesidades y recursos comunitarios suelen estar dispersos en WhatsApp, Facebook, llamadas y contactos personales.

## Usuarios objetivo
- Habitantes del barrio.
- Personas que necesitan ayuda.
- Vecinos que ofrecen ayuda o recursos.
- Comercios/personas con oportunidades de empleo local.
- Líderes comunitarios como usuarios institucionales futuros.

## Preguntas
1. ¿Qué ayuda se solicita con mayor frecuencia?
2. ¿Dónde busca actualmente esa ayuda?
3. ¿Qué información necesita antes de aceptar ayuda?
4. ¿Qué tan útil sería un mapa?
5. ¿Qué categorías deberían ser accesos rápidos?
6. ¿Qué barreras de accesibilidad existen?

## Instrumentos
Encuesta breve, entrevista semiestructurada y prueba de tareas.

> No se inventan resultados de campo. Deben completarse después de aplicar los instrumentos a usuarios reales.
