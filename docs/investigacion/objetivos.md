# Objetivos del proyecto

## Objetivo general
Desarrollar NEXO como una plataforma móvil que conecte necesidades comunitarias con personas, recursos y oportunidades cercanas, apoyándose en clasificación de solicitudes, visualización de datos y colaboración.

## Objetivos específicos del MVP
1. Implementar autenticación y perfiles.
2. Registrar y consultar necesidades.
3. Facilitar publicaciones vecinales.
4. Representar recursos mediante un mapa simplificado.
5. Mostrar indicadores y gráficos de actividad.
6. Preparar la capa de clasificación automática para NEXO AI.
7. Aplicar validaciones y controles básicos de seguridad.
