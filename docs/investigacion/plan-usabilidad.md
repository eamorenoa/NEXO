# Plan de evaluación de usabilidad

## Objetivo
Comprobar que una persona puede completar tareas básicas sin asistencia y comprender el propósito de NEXO.

## Muestra propuesta
5 a 8 usuarios representativos del público objetivo para detectar problemas de navegación y comprensión.

## Tareas
1. Registrarse. 2. Iniciar sesión. 3. Crear una necesidad. 4. Encontrar una publicación. 5. Consultar el mapa. 6. Revisar el perfil. 7. Identificar cómo pedir ayuda de emergencia.

## Métricas
Tasa de éxito, tiempo, errores, ayudas solicitadas y satisfacción de 1 a 5.

## Criterio
Los problemas repetidos generan ajustes de texto, jerarquía visual o flujo antes de la siguiente demostración.
