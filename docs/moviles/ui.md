# Protocolo de interfaz móvil — NEXO

## Principios
- Una acción principal por pantalla.
- Navegación inferior consistente.
- Contraste y tamaños táctiles cómodos.
- Componentes reutilizables.
- Estados de carga, éxito y error visibles.

## Pantallas MVP
1. Splash. 2. Login/Registro. 3. Inicio. 4. Necesidades. 5. Comunidad. 6. Mapa. 7. Perfil. 8. Notificaciones. 9. Emergencia.

El boceto original está en `docs/mockups/NEXO_boceto_referencia.png`.

## Simplificación
Donaciones y objetos se integran en publicaciones/necesidades; accesibilidad y adultos mayores se manejan como preferencias; chat y comunicación se concentran en Comunidad.
